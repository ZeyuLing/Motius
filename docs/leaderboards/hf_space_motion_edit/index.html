Metric Contract

The table is intentionally broad: semantic correctness alone cannot establish edit quality.

Factor preservation
S-Acc and A-Acc use held-out style/action prototype retrieval. Style and Content tracks swap which factor should change and which should be retained.
Semantic alignment
MM-Dist and T2M R@3 compare generated motion with the paired target caption in Universal SMPL-H uTMR space.
Paired target
M2M R@3 and M2M-Dist evaluate retrieval and distance against the exact paired target motion.
Distribution
FID uses per-sample L2-normalized motion embeddings; Diversity is reported without converting it into a ranking objective.
Physical quality
Foot skating and Jitter are recomputed from canonical 30 fps motion, not copied from method papers.
Ranking
The displayed rank uses M2M R@3 among exact-source generated methods. Source and MotionCLR diagnostics remain visible but unranked.
