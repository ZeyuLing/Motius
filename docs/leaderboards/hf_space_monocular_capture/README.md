# Monocular Motion Capture · 3DPW Test

Static result and video gallery for verified monocular motion capture methods.
GT is pinned first in the 3DPW table. Each integrated method has a public video
demo; metrics disclose target-crop versus full-frame input protocols and do not
assign a shared rank across incompatible inputs.

Benchmark data remains under its original license and is never uploaded to this
Space. SOMA methods participate only through the audited common-joint mapping;
they do not receive fabricated SMPL PVE values.
