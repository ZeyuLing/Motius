Protocol

A single native motion-embedding contract for every instruction editor.

Inputs
The released source motion and free-form MotionFix instruction. Methods with additional reference inputs belong to separate tracks.
Targets
The paired MotionFix target motion for all 1,013 cases; target captions are not available.
Retrieval
R@1/2/3 and AvgR use target-length-sorted candidate batches of 32, matching the released MotionLab evaluation loader.
Distribution
FID, M2M-Dist, and Diversity use the same released text_mot_match motion embeddings.
Ranking
Generated methods are formally ranked by Batch-32 R@3. GT target and the unedited source input are calibration references and never enter best/second-best selection.
Protocol and implementation: ZeyuLing/Motius. MotionFix benchmark and released baseline implementations are evaluated through the shared canonical adapter.
