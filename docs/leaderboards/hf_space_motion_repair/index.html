Protocol details

Paired population

All methods use the same 299 pair-validated BrokenAMASS clips, fixed to 100 frames at 20 fps in right-handed Z-up metres.

Support tracks

MoGenDiT uses its method-native adaptive estimate. StableMotion and MotionCanvas use the same oracle-v6 support contract. The table never hides this distinction.

Primary evaluator

uTMR R@3 is the default sort. MPJPE, global-boundary MPJPE, root error, acceleration error, skating, penetration, and jitter are paired diagnostics.
