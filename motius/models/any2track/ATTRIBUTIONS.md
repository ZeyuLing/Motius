# Any2Track Attribution

Motius provides an independently implemented ONNX wrapper for the LAFAN1
generalist v2 policy released by
[GalaxyGeneralRobotics/OpenTrack](https://github.com/GalaxyGeneralRobotics/OpenTrack).
The method is described in *Track Any Motions under Any Disturbances*.

OpenTrack is distributed under Apache-2.0. The Motius artifact includes the
official `model.onnx`, `config.json`, and upstream license, and does not import
an upstream checkout at inference time.
