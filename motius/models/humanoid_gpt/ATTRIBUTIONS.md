# Humanoid-GPT attribution

This integration packages the released non-privileged Humanoid-GPT ONNX
tracking policy and its Unitree G1-5010 MuJoCo assets. The upstream project is
[GalaxyGeneralRobotics/Humanoid-GPT](https://github.com/GalaxyGeneralRobotics/Humanoid-GPT)
and the paper is [Humanoid-GPT](https://arxiv.org/abs/2606.03985).

The upstream release provides inference and deployment code. It does not
currently provide the training code or training data, so Motius does not claim
a trainable Humanoid-GPT reproduction.
