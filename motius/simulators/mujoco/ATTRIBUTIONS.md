# MuJoCo Unitree G1 Tracking Assets

The G1 MJCF and flat scene are adapted from the Apache-2.0 licensed OpenTrack
repository and the BSD-3-Clause Unitree G1 description distributed with it:

- https://github.com/GalaxyGeneralRobotics/OpenTrack
- https://github.com/unitreerobotics/unitree_ros

Motius changes the mesh path to reuse the G1 meshes already packaged by the
library. The original Unitree BSD-3-Clause license is retained beside the
asset.
